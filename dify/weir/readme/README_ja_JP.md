# Weir：X と Reddit のデータ

Dify のワークフローとエージェントで、公開されている X（旧 Twitter）と Reddit のデータを読みます。X や Reddit のアカウントも API キーも要りません。

## ツール

| ツール | 返すもの |
| --- | --- |
| X のポストを検索 | キーワードと条件に合うポスト。アカウント、言語、最低いいね数、日付で絞り込めます。`from:` や `min_faves:` などの X の検索コマンドもそのまま使えます。 |
| ポストへの返信を取得 | 1 件のポストに付いた返信。 |
| スレッドを取得 | 投稿者がつなげたポストの連なり全体。 |
| アカウントのポストを取得 | あるアカウントの最新のポスト。 |
| Reddit を検索 | Reddit 全体か 1 つのコミュニティの投稿。 |
| Reddit のコメントを取得 | 1 件の投稿のコメント。返信の階層ごとに入れ子で返します。 |

どのツールも、API の JSON（ワークフローのノード向け）と短いテキスト（エージェント向け）を返します。ポストと Reddit のツールは、ID のほかリンクを貼り付けても使えます。

## 設定

1. [weirapp.io](https://weirapp.io) で登録し、ダッシュボードの Keys で API キーを作ります。どのアカウントも毎月 5,000 クレジットが無料で、カードは要りません。
2. Dify で Weir プラグインの設定を開き、キーを貼り付けます。プラグインが無料の呼び出しでキーを確かめます。

## 料金

Weir は前払いで、結果ごとに課金します。X のポスト 1 件で 1 クレジット、Reddit の投稿やコメント 1 件で 3 クレジット、さらにリクエスト 1 回ごとに 1 クレジットです。失敗した呼び出しは無料です。最新の料金は [weirapp.io/pricing](https://weirapp.io/pricing) にあります。

## 使用例

エージェントに「今月 r/SaaS で従量課金についてどんな意見が出ている？」と聞くと、エージェントは **Reddit を検索**（`subreddit: SaaS`、`time: month`）を呼び、読む価値のある投稿に **Reddit のコメントを取得** を使います。
