# OpenAPI 3.0 copy for API marketplaces

`openapi-3.0.json` is Weir's API description converted from the canonical OpenAPI 3.1 file at
https://api.weirapp.io/openapi.json, for importers that only read OpenAPI 3.0 (RapidAPI Studio and
similar). The canonical file always wins; regenerate this copy when the API changes.

Every endpoint takes `Authorization: Bearer <your Weir API key>`. Get a free key (5,000 credits a
month) at https://weirapp.io/signup. Docs: https://docs.weirapp.io
